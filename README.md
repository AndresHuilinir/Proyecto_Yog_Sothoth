# Proyecto Yog Sothoth

## ¿Cómo instalar y usar el programa?

### Requisito previo: Python
El programa necesita Python para funcionar.
Si no lo tienes instalado:

1. Ve a https://www.python.org/downloads/
2. Descarga la versión más reciente
3. **MUY IMPORTANTE (solo Windows):** durante la instalación,
   marca la casilla **"Add Python to PATH"** antes de hacer clic en Instalar

---

### Instalación (solo la primera vez)

#### Windows
1. Descarga o clona este repositorio
2. Entra a la carpeta del proyecto
3. Haz doble clic en **INSTALAR_WINDOWS.bat**
4. Una diga "Instalación completada" ya está listo, no hay necesidad de volver
   a realizar el mismo procedimiento

#### Mac / Linux
1. Descarga o clona este repositorio
2. Entra a la carpeta del proyecto
3. Haz doble clic en **INSTALAR_MAC_LINUX.sh**
    - Si no abre, haz clic derecho → "Abrir con Terminal"
4. Cuando diga "Instalación completada", ya está listo

---

### Usar el programa

Después de instalar, cada vez que quieras usar el programa:

- **Windows:** doble clic en **Lanzar.bat**
- **Mac/Linux:** doble clic en **Lanzar.sh**

---

### ¿Algo salió mal?

- Asegúrate de que Python esté instalado correctamente
- En Windows, intenta ejecutar el instalador como Administrador
  (clic derecho → "Ejecutar como administrador")
- Si el problema persiste, contacta a Khaos :3
